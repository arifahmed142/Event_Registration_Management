# Event_Registration_Management
This system is build to generate a list of invited guest for an event. Those who wants to join, they should fill the register form.

*Homepage:
 - Login and Registration available
 - Admin has access on user list ( Under Development )

*Register Page:
 - Every Field must be filled properly.
 - Email should be unique and not registered before.
 - Your profile photo is your responsibility :)

*Login Page:
 - Email and Password should be provided to login.
 - Email should be registered before and Password should match.

*Profile Page:
 - Members can see their provided details.
 - Members can update their information. ( Under Development )
 - They can logout from their account.
